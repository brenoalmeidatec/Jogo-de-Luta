# Lista de comandos (jogador 1, personagem virado para a direita)

## Teclas

| Tecla | Botão | O que é |
|---|---|---|
| W | ↑ | pular |
| A | ← | trás (andar para trás, defender) |
| S | ↓ | agachar |
| D | → | frente (andar para a frente) |
| **Seta esquerda** | **x** | soco fraco |
| **Seta cima** | **y** | soco forte |
| **Seta baixo** | **a** | chute fraco |
| **Seta direita** | **b** | chute forte |
| C | c | provocação / parry (com D) |
| Enter | start | pausa |

Nos comandos abaixo, **→** é D, **←** é A, **↓** é S, **↑** é W. "Toca" é apertar e soltar. Especiais usam só direções
cardeais (sem diagonal). "Seta ←" quer dizer a seta esquerda do teclado (soco fraco), para não confundir com a tecla A.

Atalho de leitura: socos = setas esquerda (fraco) e cima (forte); chutes = setas baixo (fraco) e direita (forte).

## Menus

Em todos os menus (título, modos, seleção de personagem, cenário, opções, pausa): **W/A/S/D** movem o cursor e
**Enter** confirma; **Esc** volta. As setas só valem na luta. O atalho ajusta isso a cada clique.

## Sistema (vale para os dois)

| Ação | Comando |
|---|---|
| Andar / pular | D, A / W (W+D, W+A para pular de lado) |
| Corrida / passo para trás | D, D / A, A |
| Pulinho, pulo, hiper pulinho, super pulo | toca W, segura W, S e toca W, S e segura W |
| Agachar e defender baixo | segura S (defesa baixa: S + A segurando) |
| Defesa | segurar A (trás) |
| Rolamento | seta ← + seta ↓ (x + a); com A rola para trás |
| Golpe de afastar | seta ↑ + seta → (y + b), no chão ou no ar |
| Agarrão | colado no oponente: D ou A + seta ↑ (y) |
| Parry | segura D + C |
| Levantar rápido | seta ← + seta ↓ ao cair |
| Provocação | C |
| Despertar | seta ← + seta ↓ + seta ↑ (x + a + y), com 1 estoque |

## Golpes normais

| | Em pé | Agachado (S +) | No ar |
|---|---|---|---|
| Soco fraco | seta ← | S + seta ← | seta ← |
| Soco forte | seta ↑ | S + seta ↑ (antiaéreo) | seta ↑ |
| Chute fraco | seta ↓ | S + seta ↓ | seta ↓ |
| Chute forte | seta → | S + seta → (rasteira, derruba) | seta → |

Direcionais em pé: **D + seta ↑** (y), **D + seta →** (b), **A + seta ←** (x), **A + seta ↓** (a).
Corrente de fracos: até 4 golpes fracos seguidos, um por contato (aperte de novo a cada acerto).

## Agarrões

Colado no oponente, D ou A + seta ↑ (y). Pengaró: Giro de Camisa e Queda de Ginga. Hazaki: Projeção de Faixa e
Troca de Lado. Quem é agarrado escapa apertando seta ↑ ou seta → (y ou b) a tempo.

Esta lista segue os arquivos `.cmd` e `movelist.dat` de `chars/`. O jogador 2 usa as teclas padrão do IKEMEN.
